# Lemo-Opuscar – alle Stile mit fertigen Anweisungen

Jede Anweisung unten kannst du **einzeln** in einen neuen Chat kopieren.
Du ersetzt nur das, was in `[eckigen Klammern]` steht.

**Wichtig:** Die Anweisungen funktionieren in einem Claude-Code-Chat, in dem Lemo-Opuscar installiert ist.
Installiert wird es so (im Terminal, einmalig):

```
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab
```

In der Cloud (claude.ai/code) reicht es, als Erstes zu schreiben:
`Klone https://github.com/lemomo-ai/lemo-opuscar und mach alles startklar.`

Der englische Stilname plus Ordnername in der Anweisung sorgt dafür, dass genau der richtige Stil genommen wird.

---

## Universal-Vorlage

```
Mach mit Lemo-Opuscar einen Film im Stil "[STILNAME]" (Ordner styles/[ORDNER]).
Länge: [20] Sekunden. Format: [16:9 / 9:16 Hochformat].
Sprache: Deutsch. [Mit Sprecher / Ohne Sprecher]. [Mit Untertiteln / Ohne Untertitel]. [Mit Musik / Ohne Ton].
Thema / Inhalt: [HIER DEIN THEMA ODER SKRIPT]
Halte dich genau an die STYLE.md des Stils. Schick mir am Ende die fertige MP4.
```

## ✂️ Papier-Stile (die Papercut-Animationen)

### Red Paper-cut · Ordner `papercut-red`
**So sieht es aus:** Rote Scherenschnitte wie chinesische Fensterbilder. Alles ist aus Papier ausgeschnitten, Details entstehen nur durch die ausgeschnittenen Löcher. Figuren haben Gelenke wie Papierpuppen und bewegen sich ruckelig mit 12 Bildern pro Sekunde. Höhepunkt: Papier wird gefaltet, einmal geschnitten und aufgeklappt, und es entsteht ein großes Muster. Hintergrund heller Reispapier-Ton oder dunkelblaues Nachtpapier.

```
Mach mit Lemo-Opuscar einen Film im Stil "Red Paper-cut" (Ordner styles/papercut-red).
Rote Scherenschnitt-Figuren mit Gelenken auf Reispapier und indigoblauem Nachtpapier, Papierschatten, Falten-Schneiden-Aufklappen als Höhepunkt.
Länge: [30] Sekunden. Sprache: Deutsch. [Mit / Ohne] Sprecher, [mit / ohne] Untertitel.

```

## Tipps für die Anweisung

- **Kein Ton / keine Untertitel:** einfach dazuschreiben „ohne Sound und ohne Untertitel“.
- **Hochformat für Reels/TikTok:** „Format 9:16 Hochformat, 1080×1920“.
- **Eigenes Skript sprechen lassen:** „Das ist das Sprechskript, wortwörtlich: …“.
- **Werbung:** Domain oder Produkt im Skript nennen und dazuschreiben „am Ende [domain.de] groß einblenden“.
- **Mischen geht nicht gut.** Pro Film einen Stil wählen.
